# Poliedro - Hotel en Español Colombia

Addon de localización `es_CO` para `hotel_management_odoo` 19.0. Conserva el
paquete de Cybrosys intacto; las traducciones se mantienen aquí. El hook de
carga combina las traducciones Python y JavaScript del addon con el catálogo
del módulo original, porque el paquete del proveedor no incluye `i18n/es_CO.po`.

Después de instalar o actualizar este addon, reinicie Odoo y use un usuario con
idioma Español (Colombia) para ver las traducciones. El archivo PO contiene las
traducciones de vistas, campos, ayudas, reportes, errores y dashboard.
