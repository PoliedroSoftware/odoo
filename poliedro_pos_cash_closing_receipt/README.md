# Poliedro POS - Arqueo térmico 80 mm

Extiende el cierre de sesión del Punto de Venta para imprimir el arqueo contado
en la impresora térmica IoT configurada. No modifica archivos de Odoo ni de
otros proveedores.

## Uso

1. Abra **Cerrar caja** en el Punto de Venta.
2. Complete el efectivo y los demás valores contados.
3. Presione **Imprimir arqueo** antes de cerrar la sesión.
4. Verifique la impresión y luego presione **Cerrar caja**.

El comprobante incluye ventas, efectivo, desglose por denominaciones cuando se
utiliza el conteo de billetes/monedas, entradas y salidas, medios de pago,
diferencias, observaciones y espacios para firmas.
